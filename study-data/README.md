# 我的学习档案

这里是学习记录的正式保存位置，随个人仓库一起提交。打开根目录 **启动学习库.cmd** 后，题库在本机地址 `http://127.0.0.1:17866` 运行；标记不会、答题、添加生词、标记知识点后自动写入文件。

| 文件 | 用途 |
|---|---|
| `state.json` | 正式记录：三科原始数据、版本、历史变更、迁移来源 |
| `学习档案.md` | 直接阅读的错题、不会题、知识点、生词及答案解析 |
| `agent-context.json` | 智能体完整资料，按科汇总，带题目与英语上下文 |
| `imports/*.json` | 首次迁入的浏览器学习记录，便于核对；只含本题库允许的字段 |

智能体先运行 `node tools/read.mjs learning summary`，再运行 `node tools/read.mjs learning math`（也可用 `408` / `english`）。不传科目可读取完整档案，包括历史记录。

页面左下角的“已保存到文件”表示本机正式文件已更新；“正在保存”期间请稍候。断线、磁盘写入失败或多个页面冲突会明确提示，不会显示成功。请下载应急记录后核对；多页面冲突需刷新，文件中的新记录不会被旧页面覆盖。浏览器缓存只保留失败时的应急副本，不作为正式读取来源。

关掉浏览器后，本机保存程序仍在运行；双击根目录 **停止学习库.cmd** 可停止。无需联网，无需安装 npm 依赖，使用已安装的 Node.js 22 或更新版本。仅监听本机，不向局域网开放，不注册开机启动。

自动保存的是本地文件。提交/推送 Git 是独立操作：本次交付会一起提交并推送；以后需要同步时在这个项目中明确要求提交推送即可，不会在每次做题时自动向远程发送数据。

原来的 HTML 文件仍可浏览，页面会提示未启用文件保存；需要保存的学习应从启动入口打开。普通 `python -m http.server` 不提供文件保存接口。

导入导出的 JSON 使用 `{ "schemaVersion": 1, "values": { ... } }` 格式。先停止程序，再执行 `node tools/import-study.mjs <文件>`。同一份备份不会重复导入，文件中已有不同记录时会停止并提示核对，不覆盖。

“我明确不会的知识点”可在页面左下角 **学习档案 / 标记知识点** 中填写和移除。“推断薄弱点”来自题目标签和错题分布，只是讲解线索。英语错选会在档案中自动列为需讲解题，也可点击题目下方“这题我不会”。

历史迁移只能保留当时浏览器实际存下的字段；例如早期数学只保存对/错而没保存所选选项时，不会补造选项。升级后数学选择题会额外保存所选选项。
