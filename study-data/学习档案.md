#### 2020-4 · 树与森林的转换

状态：本人标记不会

我的作答：null

标准答案：C

**题干**

已知森林 F 及与之对应的二叉树 T，若 F 的先根遍历序列是 a,b,c,d,e,f，中根遍历序列是 b,a,d,f,e,c，则 T 的后根遍历序列是 ______。

**选项**

{
  "A": "b,a,d,f,e,c",
  "B": "b,d,f,e,c,a",
  "C": "b,f,e,d,c,a",
  "D": "f,e,d,c,b,a"
}

**解析**

【考什么】森林与二叉树的转换关系：F 的先根遍历 = T 的先序遍历，F 的中根（后根）遍历 = T 的中序（后序）遍历。
【怎么解】故 T 的先序为 a,b,c,d,e,f，中序为 b,a,d,f,e,c。先序首元 a 为根，中序中 a 左侧 {b} 为左子树、右侧 {d,f,e,c} 为右子树。右子树先序 c,d,e,f、中序 d,f,e,c，根为 c，c 无右子树，左子树先序 d,e,f、中序 d,f,e 中 d 为根，d 无左子树，右子树先序 e,f、中序 f,e 中 e 为根、f 为 e 的左孩子。于是 T 的后序为 b,f,e,d,c,a。
【逐项排除】
A) b,a,d,f,e,c 是中序序列本身，不是后序。
B) b,d,f,e,c,a 把 d、f 的先后次序弄反，f 应在 e 的左子树中先输出。
D) f,e,d,c,b,a 把左子树的 b 放到了最后，根 a 反而提前。

**易错点**

森林的「先根/中根」对应二叉树的「先序/中序」，问的是 T 的「后根」即 T 的后序。

标准答案：A

**题干**

已知无向图 G 如下所示，使用克鲁斯卡尔（Kruskal）算法求图 G 的最小生成树，加到最小生成树中的边依次是 ______。

**选项**

{
  "A": "(b,f), (b,d), (a,e), (c,e), (b,e)",
  "B": "(b,f), (b,d), (b,e), (a,e), (c,e)",
  "C": "(a,e), (b,e), (c,e), (b,d), (b,f)",
  "D": "(a,e), (c,e), (b,e), (b,f), (b,d)"
}

**解析**

【考什么】Kruskal 算法：按权值从小到大选边，每次选「不与已选边构成回路」的边，选满 n-1=5 条即止。
【怎么解】边按权排序：5(b,f)、6(b,d)、7(d,f)、9(a,e)、10(c,e)、11(b,e)…… 依次判断：选 (b,f)；选 (b,d)；7 的 (d,f)，此时 d 与 f 已通过 b 连通，成回路，弃；选 (a,e)；选 (c,e)；选 (b,e)，此时 b 与 e 分属 {b,d,f} 与 {a,c,e} 两个连通分量，不成回路，选入。已得 5 条边，6 个顶点全部连通，结束。故依次为 (b,f),(b,d),(a,e),(c,e),(b,e)。
【逐项排除】
B) 把 11 的 (b,e) 排到 9、10 之前，违反按权递增的选取次序。
C) 从 9 的 (a,e) 开始，漏掉了更小的 5、6、7 三条边。
D) 同样从 (a,e) 起步，且 (b,e) 与 (b,f) 的先后也不对。

**易错点**

(d,f)=7 会被选中前就与 (b,f)、(b,d) 构成回路必须跳过，这条最容易漏判。

#### 2020-8 · 关键路径

状态：本人标记不会

我的作答：null

标准答案：B

**题干**

若使用 AOE 网估算工程进度，则下列叙述中正确的是 ______。

**选项**

{
  "A": "关键路径是从原点到汇点边数最多的一条路径",
  "B": "关键路径是从原点到汇点路径长度最长的路径",
  "C": "增加任一关键活动的时间不会延长工程的工期",
  "D": "缩短任一关键活动的时间将会缩短工程的工期"
}

**解析**

【考什么】AOE 网中关键路径与工期的定义：关键路径是源点到汇点「带权路径长度最长」的路径，其长度即最短工期。
【怎么解】关键路径按权值之和最大定义，不是边数最多。延长任一关键活动必然使最长路径更长，工期延长；缩短关键活动只有在关键路径唯一时才缩短工期，存在多条关键路径时缩短其中一条可能不改变总工期。
【逐项排除】
A) 把「权值之和最大」偷换成「边数最多」，边数最多与最长路径无关。
C) 关键活动延长一定延长工期，叙述与定义相反。
D) 存在多条关键路径时缩短一条关键活动未必缩短工期，条件不足。

**易错点**

「边数最多」是常见陷阱，AOE 网的关键路径看的是各活动持续时间之和。

#### 2020-10 · B树与B+树

状态：本人标记不会

我的作答：null

标准答案：B

**题干**

依次将关键字 5,6,9,13,8,2,12,15 插入初始为空的 4 阶 B 树后，根结点中包含的关键字是 ______。

**选项**

{
  "A": "8",
  "B": "6,9",
  "C": "8,13",
  "D": "9,12"
}

**解析**

【考什么】4 阶 B 树的插入与分裂：每个结点最多 m-1=3 个关键字，第 4 个关键字插入时上溢，取中间关键字上移到父结点。
【怎么解】插 5,6,9 得 [5,6,9]；插 13 上溢，中间关键字 9 上移，得根 [9]，左孩子 [5,6]，右孩子 [13]；插 8 落入左孩子得 [5,6,8]；插 2 落入左孩子上溢，中间 6 上移，根变 [6,9]，孩子为 [2,5]、[8]、[13]；插 12 落入 [13] 得 [12,13]；插 15 得 [12,13,15] 上溢，中间 13 上移，根变 [6,9,13]。此时根有 3 个关键字，未超过 3，停止。故根结点含 6,9。
【逐项排除】
A) 8 只是叶子结点中的关键字，没有上移。
C) 8、13 不在同一层，无法同时出现在根中。
D) 9、12 中的 12 一直在叶子结点。

**易错点**

阶与关键字数不同：4 阶 B 树每个结点最多 3 个关键字，第 4 个才分裂，且上移的是中间关键字。

对大部分元素已有序的数组进行排序时，直接插入排序比简单选择排序效率更高，其原因是 ______。
I. 直接插入排序过程中元素之间的比较次数更少
II. 直接插入排序过程中所需要的辅助空间更少
III. 直接插入排序过程中元素的移动次数更少

**选项**

{
  "A": "仅 I",
  "B": "仅 III",
  "C": "仅 I、II",
  "D": "I、II 和 III"
}

**解析**

【考什么】直接插入排序与简单选择排序在「基本有序」输入下的比较次数、移动次数、辅助空间对比。

【逐项排除】
B) III 不成立，简单选择排序的移动次数同样很少。
C) II 不成立，两者辅助空间都是 O(1)。
D) II、III 都不成立。

**易错点**

「辅助空间更少」是干扰项：直接插入和简单选择的辅助空间都只有 1 个哨兵单元。

**题干**

若任一个字符的编码都不是其他字符编码的前缀，则称这种编码具有前缀特性。现有某字符集（字符个数 ≥ 2）的不等长编码，每个字符的编码均为二进制的 0、1 序列，最长为 L 位，且具有前缀特性。请回答下列问题：

**代码**

#include <stdio.h>
#include <stdlib.h>

/* 0-1 字典树结点：lchild 走 0，rchild 走 1 */
typedef struct TrieNode {
    struct TrieNode *lchild, *rchild;
    char ch;                       /* 非 0 表示该结点是一个编码的终点，存放对应字符 */
} TrieNode;

/* 申请一个空结点 */
TrieNode *newNode(void) {
    TrieNode *p = (TrieNode *)malloc(sizeof(TrieNode));
    p->lchild = p->rchild = NULL;
    p->ch = 0;
    return p;
}

/* 把编码 code（长度 len，对应字符 c）插入字典树
   返回 1 表示仍满足前缀特性，返回 0 表示违反前缀特性 */
int insertCode(TrieNode *root, const char *code, int len, char c) {
    TrieNode *p = root;
    int created = 0;               /* 本次插入是否新建过结点 */
    int i;
    for (i = 0; i < len; i++) {
        if (code[i] == '0') {      /* 字符 '0' 走左子 */
            if (p->lchild == NULL) { p->lchild = newNode(); created = 1; }
            p = p->lchild;
        } else {                   /* 1 走右子 */
            if (p->rchild == NULL) { p->rchild = newNode(); created = 1; }
            p = p->rchild;
        }
        /* 途中遇到已有编码的终点：已有编码是本编码的前缀 */
        if (p->ch != 0 && i < len - 1) return 0;
    }
    if (!created) return 0;                       /* 本编码是已有编码的前缀 */
    if (p->lchild != NULL || p->rchild != NULL) return 0;  /* 本编码是别人前缀 */
    p->ch = c;                     /* 标记为叶结点并存放字符 */
    return 1;
}

/* 译码：把 0/1 串 s 译成字符串 out */
void decode(TrieNode *root, const char *s, char *out) {
    TrieNode *p = root;
    int t = 0, i;
    for (i = 0; s[i] != 0; i++) {
        p = (s[i] == '0') ? p->lchild : p->rchild;
        if (p == NULL) break;      /* 非法编码串 */
        if (p->ch != 0) { out[t++] = p->ch; p = root; }   /* 到叶结点，输出后回根 */
    }
    out[t] = 0;
}

/* 释放整棵树 */
void freeTree(TrieNode *root) {
    if (root == NULL) return;
    freeTree(root->lchild);
    freeTree(root->rchild);
    free(root);
}

int main(void) {
    /* 字符集 {A,B,C,D} 的编码：0, 10, 110, 111 */
    const char *code[] = {"0", "10", "110", "111"};
    char ch[] = {'A', 'B', 'C', 'D'};
    int len[] = {1, 2, 3, 3};
    int i, ok = 1;
    char out[64];
    TrieNode *root = newNode();
    for (i = 0; i < 4 && ok; i++) ok = insertCode(root, code[i], len[i], ch[i]);
    printf("前缀特性: %d\n", ok);                 /* 输出 1 */
    decode(root, "010110111", out);              /* 0|10|110|111 */
    printf("%s\n", out);                         /* 输出 ABCD */
    freeTree(root);
    return 0;
}

**解析**

【思路】前缀编码与二叉树一一对应：编码即根到叶的路径，前缀特性等价于「所有编码的终点都是叶结点，内部结点不放字符」。于是「判定」与「建树」是同一个过程，只要在插入每条编码时检查三种违例即可。
【关键步骤】① 建空根；② 逐位下移，空指针就新建；③ 检查「途中遇终点」「全程未新建」「终点还有孩子」三种违例；④ 全部通过即具前缀特性；⑤ 译码时走到叶结点就输出并回根。
【易错】忘记「终点必须无孩子」这一条（例如先插 1、再插 10 时，1 成了内部结点）；把根结点当成编码终点；译码后忘记把指针重置回根。
