# 408 真题精读系统 · 使用说明

> 双击 `index.html`（Chrome / Edge）就能用。**纯静态、离线、无依赖、无 CDN**。
> 题库：2017–2026 年 **计算机学科专业基础综合（408）** 共 10 套，**选择题 400 道 + 综合应用题 70 道 = 470 题**。
> 每道题都有：**原题 → 考什么 → 怎么解 → 逐项排除 → 易错点 → 知识点归属 → 同知识点真题串联**。

---

## 〇、一句话定位

英语那套是「文章精读」，这套是「**题目精读 + 知识体系 + 生题本**」：

- **选择题**是主角：40 题逐题拆知识点，看完就知道这 2 分考的是哪一行考纲。
- **综合题**（尤其数据结构的算法设计）给**完整 C 代码 + 复杂度 + 易错点**，可以直接照着背模板。
- **不会的题**点一下进「生题本」，按知识点聚合，之后集中攻。

---

## 一、四个视图

| 视图 | 干什么 | 快捷键 |
|---|---|---|
| **试卷** | 左年份 → 中题目 → 右解析，三栏同屏 | `1` |
| **知识体系** | 学科 → 模块 → 知识点 三级树，每点标「近十年考几次 / 我错几次」 | `2` |
| **生题本** | 不会 / 做错的题按知识点聚合，可导出 Markdown、CSV | `3` |
| **统计** | 正确率、学科分布、年份 × 学科矩阵、薄弱知识点 Top15、高频知识点 | `4` |

## 二、两种模式

| 模式 | 行为 |
|---|---|
| **精读**（默认） | 答案和解析直接展开，当教材看 |
| **自测** | 先点选项，立刻判对错；**错了自动进生题本**，并记下你选的是哪个 |

## 三、怎么用（推荐动作）

1. **第一遍**：精读模式，从 2017 开始按年份刷，每题看完解析点「解析 →」看右栏。
2. **标记**：一眼不会的直接点 `✎ 不会`（快捷键 `w`），别硬想。
3. **自测**：第二遍切自测模式，只做「生题本」里那些题。
4. **串知识点**：右栏「同知识点真题」会把 9 年里考同一考点的题列出来 —— 408 最爱重复考同一个点换皮。
5. **导出**：生题本 → 「复制 Markdown」→ 粘回对话，让我按知识点给你出专题。
6. **统计**：每周看一次「薄弱知识点 Top15」，那就是你下一周该补的模块。

## 四、快捷键

| 键 | 作用 |
|---|---|
| `1`–`4` | 自测模式下选 A–D |
| `j` / `k` | 下一题 / 上一题 |
| `a` | 解析展开 / 折叠 |
| `w` | 标记「不会」 |
| `m` | 精读 ↔ 自测 |
| `/` | 聚焦搜索（题干 / 知识点 / 年份 / 选项） |
| `Esc` | 关抽屉 / 清搜索 |

## 七、已知边界

- **2026 年**（2025 年 12 月考的那套）目前没有公开的扫描版官方解析，数据来自网络文字版 + 逐题重写解析；个别依赖插图的题已按「答案 + 文字条件」反推补全，`figure` 里标注了「原卷图示缺失」。其余 9 年是官方扫描件。
- 官方解析 PDF 里的图（二叉树、流水线、电路、时序图）是图片，OCR 拿不到；这些题在 `figure` 字段用**文字描述**重建了结构（按层序 / 按位宽 / 按权值），不影响做题。综合题的**代码**另有「⤢ 全屏」按钮，可宽屏看完整实现。
- 答案以「官方参考答案」页为准（每份解析 PDF 第 1 页有 40 题答案表），生成时已逐题比对；答案表与解析正文冲突处、以及原卷印刷勘误，都写在该题的 `trap` 里（例如 2023 年 43 题 `int a[24][24]` 与 `j < 64` 矛盾、2019 年 36 题 10Mb/s 与解析 100Mb/s 口径不一致）。
- 各年 `dist` 是**该年卷面实际分值**（四科 45/45/35/25 为大纲参考值，个别年份因综合题分值分配会有 ±1~2 分的浮动），统计页按实际值算。
- 生题本存 `localStorage`，**换浏览器 / 清缓存会丢**，重要记录请导出 Markdown。
- 代码高亮是极简 C 语法（关键字/字符串/注释/数字），不追求编译级准确。
