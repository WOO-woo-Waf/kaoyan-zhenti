## 二、选择题（choices[]，恰好 40 题）

```jsonc
{
  "no": 1,
  "id": "2017-1",                  // 必须 "年份-题号"
  "subject": "数据结构",             // 数据结构 | 计算机组成原理 | 操作系统 | 计算机网络
  "module": "绪论",                 // 见 §五 模块清单，必须一字不差
  "point": "时间复杂度分析",          // 知识点（短，4–12 字，同类必须同写法，用于聚合）
  "type": "计算题",                 // 概念辨析 | 计算题 | 图示分析 | 代码分析 | 推理判断
  "difficulty": 3,                 // 1–5
  "stem": "下列函数的时间复杂度是 ______。",  // 题干，空位统一写 ______（6 个下划线）
  "code": "int func(int n){\n    int i = 0, sum = 0;\n    while (sum < n) sum += ++i;\n    return i;\n}",
  "options": { "A": "O(log n)", "B": "O(n^1/2)", "C": "O(n)", "D": "O(n log n)" },
  "answer": "B",                   // 单个大写字母
  "analysis": "【考什么】…\n【怎么解】…\n【逐项排除】\nA) …\nB) …\nC) …\nD) …",
  "whyWrong": { "A": "…", "C": "…", "D": "…" },   // 可选，与 analysis 里的排除段可重复
  "trap": "常见坑：把 while 的 n 当循环次数。",     // 可选，一句话
  "tags": ["高频"]                 // 可选：高频 | 易错 | 超纲 | 送分
}
```

**硬性要求**

1. `no` 1–40 连续不缺号；`id` = `"年份-题号"`。
2. `options` 必须 A/B/C/D 四项齐全，**原文照抄**（含 `O(n^1/2)` 这种写法，不要改成 LaTeX）。
3. `answer` 必须与「解析 PDF」里标注的答案一致；有争议时在 `trap` 里写「本题官方答案 X，另有 Y 说」。
4. `analysis` 必须含 `【考什么】` 与 `【怎么解】` 两段，排除段可选。
5. 题干里的图（二叉树/电路/流水线图）用 `stem` 文字描述 + `figure` 字段（可选）写「图示说明」，例如
   `"figure": "一棵 9 结点二叉树：根 a，左 b 右 c……（按层序描述）"`。
6. 代码题必须把**真题原始代码**放进 `code`（缩进保留 4 空格），不要另写。

## 四、知识体系（`data/kb.js`）

```js
window.__KB__ = {
  subjects: [
    { id: "DS", name: "数据结构", score: 45, color: "#6aa9ff",
```
