# 408 真题数据生产规范（给写数据的 agent）

你要做的事：把**某一年的扫描版真题 + 官方解析**，转成 `data/paper/<年份>.js` 一个文件。
产出必须能通过 `node data/_build/check.mjs <年份>`（全绿）。

---

## 一、输入（只读）

| 内容 | 路径 |
|---|---|
| 真题 OCR（8 页，按阅读顺序重排，含缩进） | `D:\buff\考研\408\_ocr\<年份>_真题\p01.txt … p08.txt` |
| 真题原页图片（补图示用） | `D:\buff\考研\408\_ocr\png\<年份>_真题\p01.png … p08.png` |
| 官方解析 OCR（10 页左右，**第 1 页是 40 题答案表**） | `D:\buff\考研\408\_ocr\<年份>_解析\p01.txt … p10.txt` |
| 数据契约 | `D:\buff\考研\408\精读系统\SCHEMA.md` |
| 知识体系（module / point 只能取这里） | `D:\buff\考研\408\精读系统\data\kb.js` |
| 写法样例 | `D:\buff\考研\408\精读系统\data\paper\2017.js`（占位样例，看结构即可） |

**OCR 有噪声**：`ⅡI`/`IⅡI`/`II` 混用、`．` 与 `.` 混用、`（` 与 `(`、公式上标丢失（`n^1/2`、`n²`）。
→ 按上下文还原成**正确的中文/数学写法**（`I. II. III. IV.` 用罗马数字统一；幂写 `O(n^(1/2))` 或 `n^(1/2)`；下标写 `a[i]`）。
→ 但**不要改题意、不要补全题目里没有的条件**。

## 二、输出（只写你自己那一年）

`D:\buff\考研\408\精读系统\data\paper\<年份>.js`，形如：

## 三、选择题（1–40）字段硬性要求

```js
{
  no: 1, id: '2017-1',
  subject: '数据结构',          // 四选一：数据结构 | 计算机组成原理 | 操作系统 | 计算机网络
  module: '绪论',               // 必须来自 kb.js 该学科的 modules
  point: '时间复杂度分析',       // 必须来自 kb.js 该 module 的 points（一字不差）
  type: '代码分析',             // 概念辨析 | 计算题 | 图示分析 | 代码分析 | 推理判断
  difficulty: 3,               // 1–5
  stem: '下列函数的时间复杂度是 ______。',   // 空位统一 ______（6 个下划线）
  code: 'int func(int n) {\n    …\n}',      // 仅当题目本身带代码；缩进 4 空格
  figure: '…',                 // 仅当题目带图；用文字按层序/按位宽描述，不要留空
  options: { A: '…', B: '…', C: '…', D: '…' },   // 四项齐全，原文照抄
  answer: 'B',                 // 与官方答案表一致
  analysis: '【考什么】…\n【怎么解】…\n【逐项排除】\nA) …\nB) …\nC) …\nD) …',
  whyWrong: { A: '…', C: '…', D: '…' },   // 三个错误项各一句（正确项不写）
  trap: '一句话点破最容易掉进去的坑。',
  tags: ['高频']               // 可选：高频 | 易错 | 超纲 | 送分
}
```

**解析写法（这是本项目的价值所在，别糊弄）**

- `【考什么】`：1–2 句，点明**考纲上的哪一条**。例：「考二叉树遍历序列的唯一性：已知先序 + 中序可唯一确定树」。
- `【怎么解】`：**可复现的解题动作**。计算题给算式与代入过程；概念题给判定依据（定理/性质原话）。
- `【逐项排除】`：A) B) C) D) 每项一句，说明**错在哪**（与原文相反 / 无中生有 / 偷换概念 / 条件不足 / 量纲不对 …）。
- `whyWrong`：与上面对应，**只写三个错误项**，每条 10–40 字。
- `trap`：一句话，写「最容易错成什么、为什么」。
- 中文简体，术语用教材说法（如「临界区」「缺页中断」「CPI」「子网掩码」）。
- 单题 `analysis` 总长 120–400 字，宁精不滥。

## 四、综合题（41–47）

```js
{
  no: 41, id: '2017-41', subject: '数据结构', module: '图', point: '最小生成树',
  score: 10, type: '算法设计',   // 算法设计 | 计算分析 | 电路/流水线分析 | 综合应用
  difficulty: 4,
  stem: '完整题面（含所有小问的引子条件）',
  figure: '图示文字描述（如有）',
  subs: [
    { label: '（1）', ask: '写出算法思想', ans: '参考答案全文（可多行）' },
    { label: '（2）', ask: '给出 C 语言实现', ans: '见代码' }
  ],
  code: 'void Prim(…) {\n    …\n}',   // 数据结构算法题必给完整可编译 C 代码
  codeNote: '时间 O(n^2)，空间 O(n)',
  analysis: '【思路】…\n【关键步骤】…\n【易错】…',
  pitfalls: ['…', '…']
}
```

**算法题代码要求**（数据结构 41/42 题必做）

- 用 **C 语言**（408 标准：`typedef struct` + 函数，含必要的 `malloc`、边界判断）。
- 代码必须**符合题意**：题目要求「求…并返回…」就按题目签名写，不要写成伪代码。
- 至少覆盖：空表/单结点/边界下标；关键注释用 `/* */` 或 `//`。
- `codeNote` 写复杂度；`pitfalls` 写 2–4 条考场易错点（越界、忘记 free、递归深度、负权等）。

## 五、答案一致性（必须做）

1. 打开 `<年份>_解析\p01.txt`，第 1 页有 **「一、单项选择题」答案表**（如 `1. B 2. C 3. A …`）。
   - **排版年年在变**：2017/2018/2020/2021/2022 是「题号. 答案」横排；**2019 是两栏竖排**（OCR 出来是 `B`、`B`、`C`、`2.` 一堆碎片）——这种要按「01→C、02→B…」逐列还原，必要时翻 `p02.txt` 对照解析正文里「1. 解析：…因此 B 正确」反推。
   - 解析正文每题结尾常有「因此 X 正确」，**这是第二道交叉校验**：答案表 ↔ 正文结论必须一致。
2. 逐题核对 `answer`；**以答案表为准**。若答案表与解析正文冲突，`answer` 取答案表，并在 `trap` 里写「本题官方答案 X，解析正文另有 Y 说法」。
3. 综合题答案取解析 PDF 对应题号的「参考答案」。
