# 数学（一）真题精读系统 · 数据契约 v1

> 所有年份一个文件：`data/paper/<year>.js`，**纯 JS 赋值**（`file://` 下 `fetch` 会被 CORS 拦，所以不能用 JSON）。

## 1. 顶层

```js
window.__MATH__ = window.__MATH__ || {};
window.__MATH__[2016] = {
  year: 2016,
  title: '2016 年全国硕士研究生招生考试 数学（一）',
  duration: 180,
  score: 150,
  dist: { '高等数学': 82, '线性代数': 34, '概率论与数理统计': 34 },  // 该年卷面实际分值
  choices: [ /* 选择题 */ ],
  fills:   [ /* 填空题 */ ],
  bigs:    [ /* 解答题 */ ]
};
```

## 2. 题型结构（按年份不同！）

| 年份 | 选择题 | 填空题 | 解答题 | 选择题分值 | 填空分值 | 解答题合计 |
|---|---|---|---|---|---|---|
| 2016–2020 | 8（1–8） | 6（9–14） | 9（15–23） | 4 | 4 | 94 |
| 2021–2026 | 10（1–10） | 6（11–16） | 6（17–22） | 5 | 5 | 70 |

> **2021 考研（2020 年 12 月）起题型改革**：10 选择（每题 5 分）+ 6 填空（11–16，每题 5 分）+ 6 解答（17–22，17 题 10 分、18–22 各 12 分，共 70 分）。

**题号必须连续**：`choices` 里 `no` 从 1 开始，`fills` 接着排，`bigs` 接着排；`id = "<year>-<no>"`。

  point: '数列极限',             // 逐字来自 kb.js

  figure: '可选：图形/表格的文字化描述',

  analysis: {
    '考什么': '……（1–3 句，点出考点与命题角度）',

## 4. 填空题

```js
{
  no: 9, id: '2016-9',
  subject: '高等数学', module: '一元函数积分学', point: '定积分的几何应用',
  type: '计算题', difficulty: 3,
  stem: '……______。',
  answer: '$\\dfrac{\\pi}{4}$',   // 纯答案（含必要单位），允许 LaTeX
  analysis: { '考什么': '…', '怎么解': '…', '逐项排除': '本题为填空，无选项；常见错误：…' },
  trap: '…'
}
```
> 填空题没有选项，`analysis['逐项排除']` 写成「**无选项；易错点是……**」，不要空着（校验脚本会检查三段齐全）。

## 5. 解答题

```js
{
  no: 15, id: '2016-15',
  subject: '高等数学', module: '一元函数积分学', point: '不定积分计算',
  score: 10,                     // 该题满分（照原卷）
  type: '计算题',                // 计算题 / 证明题 / 综合应用
  difficulty: 4,
  stem: '（本题满分 10 分）……',
  subs: [                        // 小问：没有小问就写一个小问
    { label: '(1)', ask: '求 ……', ans: '完整解答（含关键步骤与最终结果）' }
  ],
  analysis: {
    '思路': '看到什么 → 想到什么方法（2–4 句）',
    '关键步骤': '分步写清：①…②…③…',
    '易错': '……'
  },
  pitfalls: ['踩坑点 1', '踩坑点 2']   // ≥2 条
}
```

## 6. 公式写法（**最重要**）

- 行内：`$f(x)$`；独立成行：`$$\\int_0^1 x^2\\,dx = \\frac13$$`
- **JS 字符串里反斜杠要写两个**：`'$\\frac{1}{2}$'`
- 常用：`\\frac{a}{b}` `\\int_a^b` `\\sum_{n=1}^{\\infty}` `\\lim_{x\\to 0}` `\\sqrt[3]{x}` `\\alpha` `\\lambda_1` `\\begin{vmatrix}a&b\\\\c&d\\end{vmatrix}` `\\begin{cases}…\\end{cases}` `\\vec{a}` `\\iint_D` `\\oint_L` `\\mathrm{d}x` `\\infty` `\\cdot` `\\neq` `\\leqslant` `\\Rightarrow` `\\sim` `\\left(\\right)`
- 不要在 `$...$` 里写中文（KaTeX 不认），中文放公式外面
- 题干里的填空横线统一写 `______`（6 个下划线）
