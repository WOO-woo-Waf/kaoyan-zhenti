## 二、怎么用

**版面是「文章 | 题目」左右两栏，同屏对照，不跳转。**

1. 双击 **`paper.html`**（Chrome / Edge）。
2. 左栏选年份（2026 在最上）→ 中栏切题型 Tab → 阅读再切 `Text 1–4`。
3. **左栏是文章**，每句后面有「精读 ▾」——点开就是
   - **主干**：这句话的骨架（主语 + 谓语 + 核心宾语）
   - **意群表**：逐块切分 + 功能标签（主语 / 谓语 / 定语从句 / 介词短语…）
   - **中文**：该句译文
4. **右栏是题目**：题干 + A/B/C/D + 正确答案 + 官方解析，全部直接展开。
5. 顶栏四个开关：`整段/逐句`、`精读全开/全关`、`中文`、`解析`。
6. **划选任意单词** → 浮出工具条 → 「有道」在新标签查义。
7. 觉得该记的词 → 「★ 加入生词本」→ 右上「生词本」→「复制全部」→ 粘回对话，我记进 `..\生词本.md`。

## 五、重建流水线（PDF 更新后重跑）

```powershell
$py = 'D:\Anaconda\python.exe'
cd 'D:\buff\考研\英语\精读系统'
& $py -X utf8 'data\wx\_pdf2wx.py'   # 1. 真题 PDF -> 完形原文 + 20 题选项
& $py -X utf8 'data\wx\_jieshi.py'   # 2. 解析 PDF -> 完形 20 题逐题解析
& $py -X utf8 'data\wx\_merge.py'    # 3. 合并 -> data\wx\20XX.js
& $py -X utf8 'data\wx\_paper.py'    # 4. 整卷五大题 -> data\paper\20XX.js
```

## 六、已知边界

- 2007–2011 是**旧卷**（2010 前不分英语一/二），结构略有差异，解析质量略逊于 2012+。
- 2012–2026 是重点，左栏标 `精做`。
- 完形以外的年份没有手写「逐句精讲」，只有官方解析原文（已排版成彩色标签，可直接读）。
- 答案以官方解析 PDF 为准；阅读 400 题已全量自校验通过（`【答案】` ↔ 解析 ✓ 选项）。
